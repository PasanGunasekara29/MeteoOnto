MeteoOnto Ontology Documentation

A navigable description of MeteoOnto’s meteorological concepts, relationships, modules, and vocabulary alignments.

1. Ontology overview

MeteoOnto provides a shared semantic model for meteorological observations, sensors and platforms, measurements, forecasts, datasets, places, time, extreme weather, and risk. Its modular design links these concepts to established Semantic Web vocabularies so weather information can be described and connected across systems.

This documentation brings together the core ontology and its forecasting, geospatial, extreme-weather, and risk modules. Use the cross-reference tables to search terms, or open the interactive graph to explore class nodes and property edges.

4. Modules and aligned vocabularies

MeteoOnto is published as a set of related OWL/Turtle modules. Alignment files express mappings between MeteoOnto terms and external vocabularies.

Core ontologyObservations, measured properties, results, and meteorological concepts. Forecasting moduleForecast products, models, and prediction concepts. Geospatial modulePlaces, features, geometries, and spatial relations. Extreme-weather moduleExtreme weather phenomena and their domain relations. Risk and safety moduleRisks, impacts, infrastructure, and response organizations. Alignment filesSOSA/SSN, QUDT, PROV-O, OWL-Time, GeoSPARQL, DBpedia, and SWEET.
