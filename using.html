Using Mete∞nto

Load, inspect, and query the ontology.

Use standard RDF tooling to work with Mete∞nto’s Turtle files and ask questions across classes, properties, and linked datasets.

Load with Python and RDFLib

Download the core Turtle file, then parse it as an RDF graph:

from rdflib import Graph\n\ng = Graph()\ng.parse("Meteo_Onto_Core.ttl", format="turtle")\nprint(len(g), "triples")

Query with SPARQL

For example, list named classes in the Mete∞nto core namespace:

PREFIX owl: <http://www.w3.org/2002/07/owl#>\n\nSELECT ?class WHERE {\n  ?class a owl:Class .\n  FILTER(STRSTARTS(STR(?class),\n    "http://meteo_onto.org/meteo_core/"))\n}

Replace the class pattern with terms and relationships relevant to your application. Check the ontology’s exact namespaces and axioms in the source files.
