Using Mete∞nto

Load, inspect, and query the ontology.

Use standard RDF tooling to work with Mete∞nto’s Turtle files and ask questions across classes, properties, and linked datasets.

Load with Python and RDFLib

Download the core Turtle file, then parse it as an RDF graph:

from rdflib import Graph\n\ng = Graph()\ng.parse("Meteo_Onto_Core.ttl", format="turtle")\nprint(len(g), "triples")
Get the core Turtle file ↗

Query with SPARQL

Use SPARQL 1.1 to inspect the classes declared in Mete∞nto’s core namespace. This query returns each class IRI and its label when one is available.

PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX core: <http://meteo_onto.org/meteo_core/>

SELECT DISTINCT ?class ?label
WHERE {
  ?class a owl:Class .
  FILTER(STRSTARTS(STR(?class), STR(core:)))
  OPTIONAL { ?class rdfs:label ?label }
}
ORDER BY ?class

Classes without an rdfs:label still appear with their IRI. This query reads class declarations from the ontology schema. To query weather observations or other instance data, load a graph that also contains those data triples. Check the ontology files for the exact terms and axioms available in your version.

Competency questions and SPARQL examples

The examples below pair each meteorological competency question with a SPARQL query and its sample result.

Example data: The supplied results were generated from a synthetic graph containing 45 triples. They are illustrative examples, not live weather observations. Check each term against the current Turtle files before using the query with another dataset.
CQ1 · Which weather observations were recorded at a specific geographic location during a given time interval, and what observable properties and measurements were associated with those observations?

SPARQL query

PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
PREFIX core: <http://meteo_onto.org/meteo_core/>
PREFIX geo: <http://meteo_onto.org/meteo_geo/>
PREFIX forecast: <http://meteo_onto.org/meteo_forecasting/>
PREFIX ext: <http://meteo_onto.org/meteo_extreame/>
PREFIX risk: <http://meteo_onto.org/meteo_risk/>

SELECT DISTINCT ?observation ?location ?property ?start ?finish ?result ?value ?unit
WHERE {
  ?observation core:hasLocation ?location ;
               core:hasObservationTime ?time ;
               core:observedProperty ?property ;
               core:hasResult ?result .
  ?location geo:hasName "Colombo" .

  ?time core:hasBeginTime ?begin ;
        core:hasEndTime ?end .
  ?begin core:hasTime ?start .
  ?end core:hasTime ?finish .

  FILTER(
    ?start <= "2026-01-02T00:00:00Z"^^xsd:dateTime &&
    ?finish >= "2026-01-01T00:00:00Z"^^xsd:dateTime
  )

  OPTIONAL { ?result core:hasValue ?value }
  OPTIONAL { ?result core:hasUnit ?unit }
}

CQ3 · Which forecast predictions are available for a specific location and forecast-valid time, and what forecast data and results support those predictions?

SPARQL query

PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
PREFIX core: <http://meteo_onto.org/meteo_core/>
PREFIX geo: <http://meteo_onto.org/meteo_geo/>
PREFIX forecast: <http://meteo_onto.org/meteo_forecasting/>
PREFIX ext: <http://meteo_onto.org/meteo_extreame/>
PREFIX risk: <http://meteo_onto.org/meteo_risk/>

SELECT DISTINCT ?prediction ?location ?validAt ?property ?result ?value ?probability ?forecastData
WHERE {
  ?prediction forecast:hasLocation ?location ;
              forecast:hasForecastValidTime ?validTime ;
              forecast:observedProperty ?property ;
              forecast:hasForecastResult ?result .
  ?location geo:hasName "Colombo" .
  ?validTime core:hasTime ?validAt .

  FILTER(
    ?validAt >= "2026-01-01T12:00:00Z"^^xsd:dateTime &&
    ?validAt <  "2026-01-01T13:00:00Z"^^xsd:dateTime
  )

  OPTIONAL { ?result forecast:hasValue ?value }
  OPTIONAL { ?result forecast:hasProbability ?probability }
  OPTIONAL { ?result forecast:hasForecastData ?forecastData }
}

CQ5 · Which extreme weather events occurred or are forecast to occur in a particular administrative region, and what were their duration, spatial extent, status, and severity?

SPARQL query

PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
PREFIX core: <http://meteo_onto.org/meteo_core/>
PREFIX geo: <http://meteo_onto.org/meteo_geo/>
PREFIX forecast: <http://meteo_onto.org/meteo_forecasting/>
PREFIX ext: <http://meteo_onto.org/meteo_extreame/>
PREFIX risk: <http://meteo_onto.org/meteo_risk/>

SELECT DISTINCT ?event ?region ?duration ?extent ?status ?severity
WHERE {
  ?event ext:occursInAdministrativeRegion ?region .
  ?region geo:hasName "Colombo District" .

  OPTIONAL { ?event ext:hasEventDuration ?duration }
  OPTIONAL { ?event ext:hasSpatialExtent ?extent }
  OPTIONAL { ?event ext:hasEventStatus ?status }
  OPTIONAL {
    ?event ext:isEventOf ?representation .
    ?representation ext:hasSeverity ?severity .
  }
}
