Mete∞nto

Meteorology Knowledge Connected.

Mete∞nto connects the key layers of meteorological data: observations, sensors, and platforms through SOSA/SSN; units through QUDT; time through OWL-Time; places and spatial features through GeoSPARQL and DBpedia; and data collections and provenance through PROV-O. Its own forecasting, geospatial, extreme-weather, and risk modules add domain detail, while SWEET alignments connect atmospheric and hydrological phenomena with environmental science. Together, these links describe what happened, how it was measured, where and when it occurred, and how forecasts and datasets relate.

Use & cite

Ontology files, ready to use.

Download source and module files directly from the repository. Turtle is human-readable and works with common RDF tools.

Load with Python

Parse the core ontology with RDFLib, then query its classes and properties.

from rdflib import Graph
g = Graph()
g.parse("Meteo_Onto_Core.ttl", format="turtle")
print(len(g), "triples")

Query with SPARQL

For example, list named classes in the core namespace.

PREFIX owl: <http://www.w3.org/2002/07/owl#>
SELECT ?class WHERE {
  ?class a owl:Class .
  FILTER(STRSTARTS(STR(?class),
    "http://meteo_onto.org/meteo_core/"))
}
